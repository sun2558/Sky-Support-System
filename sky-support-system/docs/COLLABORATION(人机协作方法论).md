# 开发方法论：人机协作模式说明

## 协作模式
本项目采用**人机协作开发模式**：
- **人类角色**：领域专家、架构师、产品经理、质量把控
- **AI角色**：技术框架提供者、代码生成器、迭代加速器

## 具体分工
### 人类贡献：
1. 气象领域知识与分析能力
2. 项目战略规划与棋盘思维
3. 质量要求与迭代方向把控
4. 真实经历与使命叙事构建

### AI贡献：
1. Python代码框架与最佳实践建议
2. 模块化设计思路与架构方案
3. 快速原型生成与多方案对比
4. 文档结构化与叙事整理

## 透明度说明
所有AI生成的代码均经过：
1. 人类领域知识验证
2. 实际运行测试
3. 多次迭代优化
4. 最终人类验收

## 项目意义
本项目的开发过程本身，即是**人机协作解决复杂问题**的一次实证探索。
